BIRTHDAY PREMIUM V9 — SIGNATURE EDITION

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder birthday-premium-v9-signature di VS Code.
3. Klik kanan index.html.
4. Pilih Open with Live Server.
5. Tekan Ctrl + Shift + R jika browser masih menampilkan versi lama.

Struktur proyek:
- index.html
- css/ berisi CSS yang dipisah per fitur
- js/ berisi JavaScript yang dipisah per fitur
- images/ untuk foto
- videos/memory.mp4 untuk video
- music/background.mp3 untuk lagu

Fitur utama:
- Loading screen premium.
- Opening malam dengan bulan dan bintang.
- Amplop 3D yang bisa diklik atau drag.
- Surat cinta dengan typing effect.
- Buku kenangan 3D.
- Galeri Polaroid yang bisa digeser dan diperbesar.
- Pemutar video mini cinema.
- Music player.
- Balon yang bisa di-pop.
- Lilin, asap, confetti, hati, dan kembang api.
- Ending dengan typing effect dan film credits.
- Cursor sparkle dan sakura.
- Responsive untuk HP dan laptop.
